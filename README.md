# Spark

Apache Spark learning and reference workspace.

This repository contains William Fox's older Spark/Scala/Zeppelin examples and sample datasets, reorganized into a clean structure.

## Layout

- `notebooks/zeppelin/` — exported Apache Zeppelin notebooks
- `examples/scala/` — Scala/Spark snippets
- `data/` — small sample datasets used by the examples

## Repository boundaries

- **Spark** — Spark/Scala and Zeppelin-specific examples
- **FoxPySpark** — Python/PySpark examples and utilities
- **Data_Engineering** — broader data-engineering patterns and cross-platform examples
- **Flink** — Apache Flink streaming/batch experiments

Large production datasets, credentials, Spark event logs, checkpoints, and generated output should not be committed.
